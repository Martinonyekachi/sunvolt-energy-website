# Sunvolt Energy

A responsive React and Vite portfolio concept for a solar and battery systems company serving Nigerian homes and businesses.

## Run locally

```sh
npm install
npm run dev
```

## Checks and production preview

```sh
npm run lint
npm run build
npm run preview
```

## Project notes

- Built with React, standard CSS, and Vite; no UI framework or icon package is required.
- Project imagery and Google Fonts load from external services.
- The contact form performs client-side validation only and does not send submissions.
- Company figures, project specifications, testimonials, and contact details are illustrative portfolio content.
